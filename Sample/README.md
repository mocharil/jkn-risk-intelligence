# Katalog Data Portal BPJS Kesehatan (`https://data.bpjs-kesehatan.go.id/`)

Folder ini berisi seluruh **75 Dataset Publik JKN (`.xlsx`)** serta **Buku Panduan Data Sampel BPJS Kesehatan (`.pdf`)** yang tersedia di Portal Data BPJS Kesehatan (`https://data.bpjs-kesehatan.go.id/bpjs-portal/`).

> **Catatan Penting Mengenai Data Sampel Kohort Mikro (2015–2024):**
> Pada portal `https://data.bpjs-kesehatan.go.id/`, seluruh **75 dataset publik (`.xlsx`)** dan **Buku Data Sampel (`.pdf`)** dapat diunduh langsung tanpa login (dan seluruhnya telah diunduh ke dalam folder ini). Adapun file mikro-data kohort longitudinal (`126 juta baris`) memerlukan akun peneliti terdaftar yang disetujui melalui halaman `https://data.bpjs-kesehatan.go.id/bpjs-portal/action/register.cbi` dan `loginForm.cbi`.
